# Патрик & Мари — концепция мобильного приложения

Инициативная концепция ООО «ЭРГОХАВЭН», созданная на основе открытых данных. Проект не является официальным продуктом «Патрик & Мари».

В репозитории находятся два самостоятельных интерфейса:

- `/` — интерактивный mobile-first прототип приложения;
- `/case/` — адаптивная коммерческая презентация из 12 содержательных разделов.

Прототип показывает выбор доставки или самовывоза до корзины, выбор адреса/кулинарии, каталог выбранной точки, карточку позиции, корзину, время получения, безопасную симуляцию оплаты с ошибкой и восстановлением, повтор заказа с проверкой цены и наличия, вход по коду, сохранённую карту лояльности и отдельный сценарий заказа торта. Настоящие заказ, оплата, регистрация и заявка не отправляются.

## Локальный запуск

```bash
npm ci
npm run dev
```

Прототип: `http://localhost:5173/#/`

Презентация: `http://localhost:5173/case/`

Ключевые состояния открываются hash-маршрутами, например `/#/payment-error` и `/#/cake`. Обновление страницы на GitHub Pages не приводит к 404. Параметр `?seed=case` создаёт детерминированную демонстрационную сессию для прямых ссылок из презентации.

## Проверка и production build

```bash
npm run lint
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
npm run qa
```

Production build с base path GitHub Pages:

```bash
VITE_BASE_PATH=/patrick-mary-concept/ npm run build
```

`npm run qa` проверяет основные состояния прототипа на ширинах 360, 390 и 430 px, презентацию на 390, 768 и 1440 px, отсутствие горизонтального переполнения и ошибок консоли, а также путь от корзины через демонстрационную ошибку оплаты к успешному восстановлению.

## Данные и ограничения

Источники фактов и изображений, даты проверки и список продуктовых гипотез приведены в [SOURCES.md](./SOURCES.md). Товары, цены, адреса доставки, интервалы, баллы и статусы внутри прототипа являются демонстрационным содержимым, если прямо не указано иное. Возможности реальной интеграции зависят от действующих систем компании и требуют технического обследования.
